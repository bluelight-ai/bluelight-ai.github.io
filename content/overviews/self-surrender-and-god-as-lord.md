## 개요

선한목자병원 주일예배 설교 시리즈(누가복음 14-18·20장, 마태복음 6장, 출애굽기 6장)는 하나의 일관된 신학적 논증을 전개한다:

> **인간은 자기 의(自己義)로 자기를 만들고 잠가버리며, 그 자기 의가 해체되어야만 하나님의 의가 들어오고 구원이 이루어진다.**

전체 시리즈는 탕자의 여정 구조로 읽힌다:

```
독립 선언 (자기 의) → 소진·흉년 (충돌) → 밑바닥 각성 → 귀환 (다시 봄)
```

## 핵심 신학 여정 — 탕자의 구조

전체 시리즈는 누가복음 15장 탕자의 여정으로 요약된다:

```
1단계: 독립 선언
  자기 의로 자기를 왕·제사장·주인으로 만듦
  (눅 15:11-12, 16:19, 18:9-14, 18:18-23)

       ↓

2단계: 소진·충돌
  자기 의가 외부 현실과 충돌, 자기 운영 체계 내에서 볼 수 없음
  (눅 15:14-16, 16:22-26, 18:24-25, 18:31-34)

       ↓

3단계: 밑바닥 각성
  "비로소 스스로 돌이켜" — 내가 볼 수 없는 자임을 깨달음
  양심·율법이 이것을 위해 존재함
  (눅 15:17, 18:35-43, 양심 논증)

       ↓

4단계: 귀환·다시 봄
  주여 나를 불쌍히 여기소서 → 하나님의 은혜 → ἀναβλέπω
  (눅 15:20, 17:11-19, 18:35-43, 마틴 루터)
```

## 핵심 개념 사전

### 자기 의 (Self-righteousness)
- 인간이 자기 기준으로 자기를 옳다고 여기는 구조
- 이 시리즈 전체를 관통하는 핵심 문제
- **표현 형식**:

| 형식 | 본문 | 설명 |
|---|---|---|
| 내가 맞다 | 눅 18:24-30 | 부자의 본질 — 내가 맞다는 것이 많을수록 하나님 나라와 멀어짐 |
| 자기 잔치 | 눅 16:19 | 자기 잘난 맛으로 사는 것 — 자주색 옷·세마포로 감춤 |
| 자기 우상숭배 | 눅 16:14 | φιλάργυρος=돈 사랑=자기 의 사랑 |
| 락(프로그래밍) | 눅 16:27-31 | 자기 철학으로 심장을 잠가버림 |
| 자기 안에 머묾 | 눅 18:9-14 | 자기가 기준, 질문하고 답을 자기가 가져옴 |
| 자아 유지 장치 | 눅 18:15-17 | 비교·성취·도덕·관계·종교로 자기 의미 생산 |
| 자기 기준 | 눅 18:18-23 | 행함으로 선함에 도달할 수 있다는 믿음 |
| 소유권 주장 | 눅 20:9-18 | 포도원을 내 것으로 여기고 주인을 인정하지 않음 |
| 자기 운영 체계 | 눅 18:31-34 | 자기 중심 해석 체계로는 그리스도를 봐도 못 알아봄 |

### 자기 의가 해체되는 경로

```
말씀이 임함 (ἕλκος — 헬코스)
  → 내면의 죄·교만이 드러남 (눅 16:19-21, 평양 대부흥)

βάσανος (시금석)
  → 자주색 옷(자기 의)·세마포(형식적 경건)가 긁혀 나감 (눅 16:22-23)

락에 균열
  → 병·상실·밑바닥·흉년 (눅 15:14-16, 16:23-26)

양심·율법의 역할
  → 내가 볼 수 없는 자임을 깨닫게 함 (눅 18:35-43)

        ↓

"주여 나를 불쌍히 여기소서"
= 자기 의 포기, 내가 맞다는 구조 해체

        ↓

하나님의 의를 받음 = 구원 = ἀναβλέπω (다시 봄)
```

### 자기 의 vs 그리스도의 의

| | 자기 의 | 그리스도의 의 |
|---|---|---|
| 비유 | 음식물 쓰레기 (눅 16:14-18b) | 귀한 선물 |
| 바울 표현 | σκύβαλα (배설물, 눅 16:8-14) | 그리스도를 얻음 |
| 이름 | 내 이름 = 거절 | 그리스도의 이름 = 입성 |
| 문 | 낙타·바늘귀 (불가능) | 은혜로 활짝 열림 |
| 하나님의 반응 | 미움·거절 (눅 16:14-15) | 인정·영접 |

### ᾅδης (하데스) 재해석
- 지옥의 물리적 공간이 아니라 **우리 안에 한 번도 드러난 적 없는 죄의 실체**
- 자주색 옷·세마포(자기 의)로 감추고 살면 평생 드러나지 않음
- 진리의 말씀(시금석, βάσανος)이 긁어낼 때 드러남 → 그 상태가 "고통"
- 곰팡이 예화: 같은 음부 속 사람끼리는 서로 정상인 줄 앎. 새 바람(그리스도)이 필요.

### 운영 체계 (OS) 개념
- 보는 것은 눈이 아니라 운영 체계가 보는 것 (비르길 케이스, 프라카슈 프로젝트)
- 자기 중심 OS로는 그리스도를 봐도 알아보지 못함
- **십자가 = OS 전환**: 자기 중심 OS를 못 박음 → 그리스도의 OS(새로운 눈)
- 타이거 우즈: 기존 스윙폼(맞다) 포기 → 새 OS → 메이저 6회 우승

### 양심 = 율법의 기능
- 양심의 목적: "의롭게 살라"가 아님 (아무도 이룰 수 없으므로)
- 양심의 실제 목적: 내가 볼 수 없는 자임을, 하나님 앞에 의롭지 못한 자임을 깨닫게 함
- 양심 → "주여 나를 불쌍히 여기소서" → ἀναβλέπω (다시 봄)

### 두 죽음의 문법
| | 나사로 | 부자 |
|---|---|---|
| 이 세상에서 | 말씀(부스러기) 받아먹음 → 헌대(실체) 드러남 | 자기 의로 감추며 잔치 → 실체 한 번도 안 드러남 |
| 죽음의 문법 | 부정사 (전환·목적) | 단순 과거 (종결·확정) |
| 죽음의 기능 | 실체 그대로 언약의 심장부로 전환 | 숨겼던 실체가 영원히 확정 |

## 4단계 신학 구조 (전체 시리즈)

### 1단계 — 문제: 자기 의로 잠긴 인간

인간은 스스로 자기를 만들고 주인이 되려 한다.

- **독립 선언**: "내 분깃을 내게 주소서" — 하나님으로부터 분리 선언 (눅 15:11-12)
- **자기 잔치**: 자주색 옷(왕)·세마포(제사장) = 자기 의로 스스로 왕·제사장 됨 (눅 16:19)
- **φιλάργυρος**: 돈 사랑=자기 의 사랑 = 자기 우상숭배 (눅 16:14)
- **락(프로그래밍)**: 자기 언어·철학으로 심장을 잠가버림 → 죽은 자가 살아나도 믿지 못함 (눅 16:27-31)
- **자아 유지 장치**: 비교·성취·도덕·관계·종교로 자기 의미를 자기가 생산 (눅 18:15-17)
- **자기 운영 체계**: 자기 중심 OS로 세상을 해석 → 그리스도를 봐도 못 알아봄 (눅 18:31-34)
- **"내가 맞다"**: 자기 의의 또 다른 이름 — 이것이 많을수록 하나님 나라와 멀어짐 (눅 18:24-30)

### 2단계 — 충돌: 하나님의 기준이 드러남

자기 의와 하나님의 의가 만날 때 반드시 충돌이 일어난다.

- **말씀이 임함 (ἕλκος)**: 진리의 말씀이 강력히 임할 때 내면의 죄·교만이 드러남 (눅 16:19-21)
- **βάσανος (시금석)**: 말씀이 긁어낼 때 자기 의의 겉껍데기가 벗겨지고 ᾅδης만 남음 (눅 16:22-23)
- **카스마(구렁텅이)**: 은혜를 받아들이지 못하는 구조로 살면 점점 벌어져 건너갈 수 없음 (눅 16:23-26)
- **머릿돌과의 충돌**: 피할 수 없는 충돌 — 깨어지거나 소멸되거나 (눅 20:9-18)
- **절대 기준**: "하나님 외에 선한 이 없다" — 자기 기준 무효화 (눅 18:18-23)
- **양심의 고발**: 양심대로 살 수 있는 자 없음 → 내가 볼 수 없는 자임의 폭로 (눅 18:35-43)

### 3단계 — 각성: 비로소 자기 실체를 봄

- **밑바닥**: "비로소 스스로 돌이켜" — 소진·흉년 없이는 각성이 없음 (눅 15:17)
- **여리고 = 무너짐**: 무너진 자가 가나안에 들어감 — 길가에 앉은 맹인 (눅 18:35-43)
- **"내가 맞다" 해체**: 타이거 우즈처럼 기존 시스템을 버려야 새 시스템을 받을 수 있음 (눅 18:24-30)
- **OS 전환의 조건**: 자기 중심 OS를 십자가에 못 박아야 그리스도의 OS가 생김 (눅 18:31-34)
- **마틴 루터**: 10년 자기 의 추구 → 지옥 같은 마음 → 로마서 1:17 → 천국의 문 (눅 18:35-43)

### 4단계 — 전환: 자기 의의 해체와 하나님의 의 수납

- **"주여 나를 불쌍히 여기소서"**: 자기 의를 내려놓은 자의 유일한 고백 (눅 18:35-43)
- **βιάζεται (침입)**: 자기 의를 스스로 깨뜨리고 그리스도의 의를 붙잡아 들어가는 것 (눅 16:14-18)
- **귀환**: 문제 해결이 아닌 예수 그리스도에게로 돌아가는 것 = 근원적 해결 (눅 17:11-19)
- **ἀναβλέπω (다시 봄)**: 육안의 눈이 닫히고 그리스도를 보는 영적 눈이 열림 (눅 18:35-43)
- **약함으로 나아감**: 약함이 하나님의 강한 손을 움직이는 힘 (출 6:1-7)
- **그리스도의 이름**: 내 이름(자기 의)이 아닌 그리스도의 이름으로만 하나님 앞에 설 수 있음 (눅 16:14-18b)
- **십자가 = 하나님의 맞음 포기**: 하나님이 먼저 자기 맞음을 십자가에 내려놓으심 → 우리도 동참 (눅 18:24-30)

```
  자주색 옷·세마포 (눅 16)   락 (눅 16)    뽕나무 (눅 17)
        │                      │                 │
        └──────────────────────┴─────────────────┘
                               │
                    자기 의 / 자기 운영 체계(OS)
                               │
           ┌───────────────────┼───────────────────┐
           │                   │                   │
      ᾅδης(내면 실체)     병뚜껑(구조)       소유권 탈취
      (눅 16:22-23)       (눅 16:23-26)      (눅 20)
                               │
                    ↓ 충돌 (βάσανος·ἕλκος·양심)
                               │
                  머릿돌 = 그리스도 = 절대 기준
                               │
                    ↓ 두 가지 결과
              깨어짐(구원)          소멸(심판)
              ἀναβλέπω              ᾅδης 확정

해체의 예화들:
  개미와 돌 → 자기 의 0 (눅 16:1-7)
  타이거 우즈 → 기존 OS 포기 후 더 큰 성취 (눅 18:24-30)
  마틴 루터 → 10년 자기 의 → 지옥 → 로마서 → 천국 문 (눅 18:35-43)
  비르길·프라카슈 → OS 없이는 눈 떠도 못 봄 (눅 18:31-34)
  평양 대부흥 → ἕλκος = 말씀이 임할 때 내면의 죄 드러남 (눅 16:19-21)
  곰팡이 예화 → 같은 음부 속 사람끼리 서로 정상인 줄 앎 (눅 16:22-23)
```

## 세 부류의 인간 (눅 16:19-21 구조)

| 부류 | 상태 | 결과 |
|---|---|---|
| **부자 (바리새인)** | 자기 의로 자기를 잔치함 — 잃은 적 없다고 여김 | 자기 맞음을 끝까지 붙잡음 → 음부 확정 |
| **나사로 (세리·탕자)** | 거지임을 앎 — 말씀(부스러기) 받아먹음 → ἕλκος | 실체 이미 드러남 → 다시 봄 → 하나님 나라 |
| **개들 (형식주의자)** | 회개했다 죄의 자리로 돌아가 핥아 먹음 | 자기 운영 체계 안으로 다시 잠김 |

## 실천적 자기 진단

1. **나의 ᾅδης는 무엇인가?** 아직 한 번도 드러난 적 없는 내면의 실체가 무엇인가? (눅 16:22-23)
2. **나는 부자인가 나사로인가?** 나는 자기 의를 잔치하는가, 거지임을 아는가? (눅 16:19-21)
3. **나의 락은 무엇인가?** 어떤 자기 언어·철학으로 심장이 잠겨 있는가? (눅 16:27-31)
4. **나의 운영 체계는 무엇인가?** 내가 보는 것이 진실인가, 내 OS의 해석인가? (눅 18:31-34)
5. **나는 "내가 맞다"가 얼마나 많은가?** 자기 의의 축적이 나를 얼마나 부자로 만들었는가? (눅 18:24-30)
6. **나의 뽕나무는 무엇인가?** 관계에서 반복되는 실족의 근원은 어디인가? (눅 17:1-10)
7. **나는 안에 있는가 바깥에 있는가?** 내가 질문하는가, 하나님께 질문받는가? (눅 18:9-14)
8. **나는 무엇을 붙잡고 있는가?** "이것을 잃으면 나는 끝이다"고 느끼는 것은 무엇인가? (눅 17:30-37)
9. **양심 앞에서 나는 어디에 서 있는가?** 양심이 무엇을 고발하는가? (눅 18:35-43)
10. **나는 주인인가 청지기인가?** 내 삶의 소유권이 누구에게 있는가? (눅 20:9-18)
11. **나는 강함을 추구하는가 약함을 인정하는가?** (출 6:1-7)
