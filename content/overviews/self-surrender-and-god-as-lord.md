## 개요

선한목자병원 주일예배 설교 시리즈(누가복음 14-20장, 마태복음 6장, 출애굽기 6장, 사도행전 9장, 에베소서 1장, 총 40편)는 하나의 일관된 신학적 논증을 전개한다:

> **인간은 자기 의(自己義)로 자기를 만들고 잠가버리며, 그 자기 의가 해체되어야만 하나님의 의가 들어오고 구원이 이루어진다.**

전체 시리즈는 탕자의 여정 구조로 읽힌다:

```
독립 선언 (자기 의) → 소진·흉년 (충돌) → 밑바닥 각성 → 귀환 (다시 봄)
```

## 핵심 신학 여정 — 탕자의 구조

전체 시리즈는 누가복음 15장 탕자의 여정으로 요약된다:

```
1단계: 독립 선언
  자기 의로 자기를 왕·제사장·주인으로 만듦
  (눅 15:11-12, 16:19, 18:9-14, 18:18-23)

       ↓

2단계: 소진·충돌
  자기 의가 외부 현실과 충돌, 자기 운영 체계 내에서 볼 수 없음
  (눅 15:14-16, 16:22-26, 18:24-25, 18:31-34)

       ↓

3단계: 밑바닥 각성
  "비로소 스스로 돌이켜" — 내가 볼 수 없는 자임을 깨달음
  양심·율법이 이것을 위해 존재함
  (눅 15:17, 18:35-43, 양심 논증)

       ↓

4단계: 귀환·다시 봄
  주여 나를 불쌍히 여기소서 → 하나님의 은혜 → ἀναβλέπω
  (눅 15:20, 17:11-19, 18:35-43, 마틴 루터)
```

## 핵심 개념 사전

### 자기 의 (Self-righteousness)
- 인간이 자기 기준으로 자기를 옳다고 여기는 구조
- 이 시리즈 전체를 관통하는 핵심 문제
- **표현 형식**:

| 형식 | 본문 | 설명 |
|---|---|---|
| 내가 맞다 | 눅 18:24-30 | 부자의 본질 — 내가 맞다는 것이 많을수록 하나님 나라와 멀어짐 |
| 자기 잔치 | 눅 16:19 | 자기 잘난 맛으로 사는 것 — 자주색 옷·세마포로 감춤 |
| 자기 우상숭배 | 눅 16:14 | φιλάργυρος=돈 사랑=자기 의 사랑 |
| 락(프로그래밍) | 눅 16:27-31 | 자기 철학으로 심장을 잠가버림 |
| 자기 안에 머묾 | 눅 18:9-14 | 자기가 기준, 질문하고 답을 자기가 가져옴 |
| 자아 유지 장치 | 눅 18:15-17 | 비교·성취·도덕·관계·종교로 자기 의미 생산 |
| 자기 기준 | 눅 18:18-23 | 행함으로 선함에 도달할 수 있다는 믿음 |
| 소유권 주장 | 눅 20:9-18 | 포도원을 내 것으로 여기고 주인을 인정하지 않음 |
| 자기 기준 방어 | 눅 20:1-8 | 기준이 공격받으면 바꾸지 않고 공격으로 방어 = 바리새인의 본질 |
| 가이사의 형상 | 눅 20:19-26 | 욕망·두려움·신경 씀이 알고리즘·돈·인정을 향할 때 = 현대의 가이사의 것 |
| 자기 운영 체계 | 눅 18:31-34 | 자기 중심 해석 체계로는 그리스도를 봐도 못 알아봄 |

### 자기 의가 해체되는 경로

```
말씀이 임함 (ἕλκος — 헬코스)
  → 내면의 죄·교만이 드러남 (눅 16:19-21, 평양 대부흥)

βάσανος (시금석)
  → 자주색 옷(자기 의)·세마포(형식적 경건)가 긁혀 나감 (눅 16:22-23)

락에 균열
  → 병·상실·밑바닥·흉년 (눅 15:14-16, 16:23-26)

양심·율법의 역할
  → 내가 볼 수 없는 자임을 깨닫게 함 (눅 18:35-43)

        ↓

"주여 나를 불쌍히 여기소서"
= 자기 의 포기, 내가 맞다는 구조 해체

        ↓

하나님의 의를 받음 = 구원 = ἀναβλέπω (다시 봄)
```

### 자기 의 vs 그리스도의 의

| | 자기 의 | 그리스도의 의 |
|---|---|---|
| 비유 | 음식물 쓰레기 (눅 16:14-18b) | 귀한 선물 |
| 바울 표현 | σκύβαλα (배설물, 눅 16:8-14) | 그리스도를 얻음 |
| 이름 | 내 이름 = 거절 | 그리스도의 이름 = 입성 |
| 문 | 낙타·바늘귀 (불가능) | 은혜로 활짝 열림 |
| 하나님의 반응 | 미움·거절 (눅 16:14-15) | 인정·영접 |

### ᾅδης (하데스) 재해석
- 지옥의 물리적 공간이 아니라 **우리 안에 한 번도 드러난 적 없는 죄의 실체**
- 자주색 옷·세마포(자기 의)로 감추고 살면 평생 드러나지 않음
- 진리의 말씀(시금석, βάσανος)이 긁어낼 때 드러남 → 그 상태가 "고통"
- 곰팡이 예화: 같은 음부 속 사람끼리는 서로 정상인 줄 앎. 새 바람(그리스도)이 필요.

### 운영 체계 (OS) 개념
- 보는 것은 눈이 아니라 운영 체계가 보는 것 (비르길 케이스, 프라카슈 프로젝트)
- 자기 중심 OS로는 그리스도를 봐도 알아보지 못함
- **십자가 = OS 전환**: 자기 중심 OS를 못 박음 → 그리스도의 OS(새로운 눈)
- 타이거 우즈: 기존 스윙폼(맞다) 포기 → 새 OS → 메이저 6회 우승

### 양심 = 율법의 기능
- 양심의 목적: "의롭게 살라"가 아님 (아무도 이룰 수 없으므로)
- 양심의 실제 목적: 내가 볼 수 없는 자임을, 하나님 앞에 의롭지 못한 자임을 깨닫게 함
- 양심 → "주여 나를 불쌍히 여기소서" → ἀναβλέπω (다시 봄)

### 두 죽음의 문법
| | 나사로 | 부자 |
|---|---|---|
| 이 세상에서 | 말씀(부스러기) 받아먹음 → 헌대(실체) 드러남 | 자기 의로 감추며 잔치 → 실체 한 번도 안 드러남 |
| 죽음의 문법 | 부정사 (전환·목적) | 단순 과거 (종결·확정) |
| 죽음의 기능 | 실체 그대로 언약의 심장부로 전환 | 숨겼던 실체가 영원히 확정 |

### 마지막 결정권자 (왕의 정의)
- **왕 = 마지막 결정권자**: 내 인생에서 최종 결정에 사인하는 자 (눅 19:28-40)
- 돈이 걸릴 때, 감정이 걸릴 때, 이해관계가 걸릴 때 — 그 순간 결정하는 자가 왕
- **두 갈래의 지명 신학**:

| | 벳바게(벳파게) | 베다니 |
|---|---|---|
| 의미 | 먹을 수 없는 첫 무화과 = 옛 이스라엘 | 두 번째 무화과(먹을 수 있음) = 새 공동체 |
| 신학적 의미 | 열매 없음·생명 없음 (왕 거부) | 열매 있음·생명 있음 (왕 받아들임) |
| 구약 병행 | 에발산 (불순종·저주) | 그리심산 (순종·축복) |

- **낮은 왕**: 나귀 새끼·십자가 — 이 왕을 받아들임 = 자기도 겸손·십자가의 방식

### 확증 편향 / 방문의 때
- **확증 편향**: "믿고 싶은 대로 보인다" — 예루살렘이 왕을 못 본 이유 (눅 19:41-44)
  - 고릴라 실험: 집중하는 곳 외에는 아무것도 안 보임 (김종훈 교수 예화)
  - 알고리즘: 유튜브가 확증 편향을 강화 → 왕을 보기 더 어려운 시대
  - 운영 체계(OS)와 연결: OS가 확증 편향의 구조적 기반
- **방문의 때(ἐπισκοπή)**: "보살핌 받는 날" = 하나님이 찾아오시는 순간
  - 금이 가는 삶 = 방문의 때: 내가 만들어 놓은 세계의 균열 = 왕이 보이기 시작하는 때
  - 심령이 가난한 자·애통하는 자·어린아이 = 자기 확신이 흔들린 자 = 왕을 볼 수 있는 자
- **에이레네(εἰρήνη)**: 왕을 받아들이는 자에게 주어지는 영원한 평화

### 기도의 정의 / 강도의 소굴
- **ἐκκρεμάννυμι** (눅 19:48): "귀를 기울여 들으므로"의 원어 = "말씀에 붙들려 매달린 상태"
- **기도의 재정의**: 간구 목록이 아니라 예수 그리스도의 말씀에 사로잡혀 붙들리고 매달리는 것
- **강도의 소굴 = 도피처** (예레미야 7장): 삶 변화 없이 제사로 죄를 면하는 구조 = 성전의 타락
  - 이사야 56장 성전의 본질(만민이 기도하는 집)과 대비
  - 한국 교회 신뢰도 꼴찌(35.4%)의 신학적 원인
- **부흥 = 말씀 운동**: 에스라·루터·칼빈·웨슬리 — 모두 말씀 선포 + 성도의 매달림(ἐκκρεμάννυμι)
- **엘리 시대** (삼상 3:1): 말씀의 이상이 희귀해진 시대 = 강도의 소굴화·교회 위기의 본질

### 자기 기준의 기원과 방어 (눅 20:1-8)
- **분리 불안**: 탄생 = 엄마와의 첫 분리 → 인간 최초의 근원 경험 → 생존 불안 → 인정 기준 형성
- **기준의 방어**: 기준이 공격받으면 바꾸지 않고 공격으로 방어 ("시끄러워, 다 이유가 있어")
- **기준이 정교할수록 못 봄**: 맹인·삭개오·어린아이 → 봄 / 대제사장·바리새인 → 못 봄
- **함정**: 새 기준을 내가 잡으면 더 교묘한 바리새인 — 예수 그리스도에게 이끌려가야 함
- **이끌려가는 삶**: 내 기준이 모두 부셔지고 예수라는 기준에 의존된 상태 = 구원받은 사람

### 네 가지 전환 과정 (행 9:1-22)
- **정점 경험**: 그리스도를 인격적으로 만남 = 변화의 출발. 이론이 아닌 경험. "내 바깥으로부터 내게 쳐들어오시는 객관적으로 존재하시는 하나님"
- **의미의 통합**: 파편화된 삶의 경험들이 그리스도 하나로 통합됨. 그리스도인에게 우연 없음.
- **해석 체계의 전환**: 뱀(물→독) vs 꿀벌(물→꿀) = 해석 체계가 다름. "팩트 자체는 없고 항상 해석만 있다." 닉부이치치: "하나님은 누구도 실수로 만들지 않으신다" → 87개국. 떨기나무 신학: 나(떨기나무)+그리스도(불꽃)=소멸되지 않는 존재 → 십자가 구조
- **삶에 존재하는 방식의 전환**: 바울 — 시각(비늘 벗겨짐)·자아관(택한 그릇, 행 9:15)·인생관(고난 수용)·행동방식 전체가 뒤집어짐
- **변화의 주어**: 내가 하는 것이 아니라 그리스도가 내 안에서 일하심. "모든 것이 하나님의 은혜였습니다"

### 데나리온 신학 / 현대의 가이사 (눅 20:19-26)
- **데나리온 = 우리**: 동전에 황제 형상이 새겨지듯, 나에게 누구의 형상이 새겨져 있는가 = 누구의 것인가
- **세 가지 자기 진단**: 욕망·두려움·신경 씀의 대상이 하나님인가 가이사인가
- **현대의 가이사**: 알고리즘(욕망 설계) · 돈 프레임("돈=능력=가치") · 인정 기준 = 보이지 않는 황제
- **인생의 주제 전환**: "무엇이 나의 소유인가" → "나의 주인은 누구인가 / 나는 누구의 것인가"
- **새로운 갈망**: "내 안에 이 형상이 지워지기를" = 최소한의 갈망 + 성령의 역사 시작

### 위대한 사고방식 3가지 (엡 1:3-12)
- **나는 누구이고 싶은가**: "나는 누구인가"(과거·현재 규정)가 아닌 "나는 누구이고 싶은가"(미래·비전이 끌어당김) — 테세우스의 배 역설과 세포 교체 주기가 보여주듯 인간에게 변하지 않는 고유한 본질은 없음. 하나님이 부르신 이름(야곱→이스라엘)이 진짜 정체성.
- **προορίζω(프로오리조) 울타리 신학**: 예정은 개인을 천국·지옥으로 미리 정한 것이 아니라 "예수 그리스도 안"이라는 울타리를 미리 쳐놓은 것. 정체성 = "나는 예수 그리스도 안에 있는가?"
- **길이 먼저, 뜻은 나중**: 닭(운영체계=길)이 있어야 계란(출력=뜻)이 계속 나옴. 경부고속도로(1968-1970): 차 없는 나라에 먼저 길을 놓자 → 자동차 산업 발전. 요 14:6: 예수님은 "길"로 자신을 소개. 뜻은 하나님이 갖고 계심 — 그 길을 걸어가면 뜻이 이루어짐.
- **기쁨과 설렘 (εὐδοκία)**: 하나님의 구속의 동력은 노력·의지가 아닌 기쁨. 에덴(기쁨의 시작)→거룩한 성 예루살렘(기쁨의 완성) = 구속사 전체가 기쁨의 여정. 하나님 아버지의 기쁘신 뜻을 알면 인생은 기쁨과 설렘이 됨.

### 요한 슬레의 묘비 / 떨기나무 신학 (행 9 + 출 3)
- **"이 세상에서 가장 좋은 것은 하나님이 우리와 함께 하심이라"**: 해석 체계 전환의 종착점 — "나는 누구인가"가 아닌 "하나님이 나와 함께 하시는가"
- **떨기나무 신학**: 쓸데없는 나(떨기나무) + 하나님의 임재(불꽃) = 소멸되지 않는 영원한 존재 → 언약궤 → 십자가로 이어지는 구속사적 상징
- **변화의 주어**: 내가 해석 체계를 바꾸는 것이 아니라 그리스도가 내 안에서 일하심 → "모든 것이 하나님의 은혜였습니다"

## 4단계 신학 구조 (전체 시리즈)

### 1단계 — 문제: 자기 의로 잠긴 인간

인간은 스스로 자기를 만들고 주인이 되려 한다.

- **독립 선언**: "내 분깃을 내게 주소서" — 하나님으로부터 분리 선언 (눅 15:11-12)
- **자기 잔치**: 자주색 옷(왕)·세마포(제사장) = 자기 의로 스스로 왕·제사장 됨 (눅 16:19)
- **φιλάργυρος**: 돈 사랑=자기 의 사랑 = 자기 우상숭배 (눅 16:14)
- **락(프로그래밍)**: 자기 언어·철학으로 심장을 잠가버림 → 죽은 자가 살아나도 믿지 못함 (눅 16:27-31)
- **자아 유지 장치**: 비교·성취·도덕·관계·종교로 자기 의미를 자기가 생산 (눅 18:15-17)
- **자기 운영 체계**: 자기 중심 OS로 세상을 해석 → 그리스도를 봐도 못 알아봄 (눅 18:31-34)
- **"내가 맞다"**: 자기 의의 또 다른 이름 — 이것이 많을수록 하나님 나라와 멀어짐 (눅 18:24-30)
- **강도의 소굴**: 삶의 변화 없이 도피처로 삼는 교회 = 내가 왕인 구조의 종교적 표현 (눅 19:45-48)
- **분리 불안 → 자기 기준**: 탄생의 분리 불안이 생존 불안·인정 기준으로 자라나고 공격받으면 방어함 (눅 20:1-8)
- **현대의 가이사**: 알고리즘·돈·인정 기준이 내 욕망을 설계 = 보이지 않는 황제에게 속한 상태 (눅 20:19-26)

### 2단계 — 충돌: 하나님의 기준이 드러남

자기 의와 하나님의 의가 만날 때 반드시 충돌이 일어난다.

- **말씀이 임함 (ἕλκος)**: 진리의 말씀이 강력히 임할 때 내면의 죄·교만이 드러남 (눅 16:19-21)
- **βάσανος (시금석)**: 말씀이 긁어낼 때 자기 의의 겉껍데기가 벗겨지고 ᾅδης만 남음 (눅 16:22-23)
- **카스마(구렁텅이)**: 은혜를 받아들이지 못하는 구조로 살면 점점 벌어져 건너갈 수 없음 (눅 16:23-26)
- **머릿돌과의 충돌**: 피할 수 없는 충돌 — 깨어지거나 소멸되거나 (눅 20:9-18)
- **기준 폭로**: 자기 기준으로 예수님을 공격하는 순간, 자기 기준의 정체가 드러남 (눅 20:1-8)
- **데나리온 신학**: 돈 안에 황제 우상숭배가 새겨진 것처럼, 나의 욕망 구조가 나의 주인을 폭로함 (눅 20:19-26)
- **절대 기준**: "하나님 외에 선한 이 없다" — 자기 기준 무효화 (눅 18:18-23)
- **양심의 고발**: 양심대로 살 수 있는 자 없음 → 내가 볼 수 없는 자임의 폭로 (눅 18:35-43)
- **확증 편향의 붕괴**: 믿고 싶은 세계에 금이 가기 시작 = 방문의 때(ἐπισκοπή) = 왕이 보이기 시작함 (눅 19:41-44)

### 3단계 — 각성: 비로소 자기 실체를 봄

- **밑바닥**: "비로소 스스로 돌이켜" — 소진·흉년 없이는 각성이 없음 (눅 15:17)
- **여리고 = 무너짐**: 무너진 자가 가나안에 들어감 — 길가에 앉은 맹인 (눅 18:35-43)
- **"내가 맞다" 해체**: 타이거 우즈처럼 기존 시스템을 버려야 새 시스템을 받을 수 있음 (눅 18:24-30)
- **OS 전환의 조건**: 자기 중심 OS를 십자가에 못 박아야 그리스도의 OS가 생김 (눅 18:31-34)
- **마틴 루터**: 10년 자기 의 추구 → 지옥 같은 마음 → 로마서 1:17 → 천국의 문 (눅 18:35-43)

### 4단계 — 전환: 자기 의의 해체와 하나님의 의 수납

- **"주여 나를 불쌍히 여기소서"**: 자기 의를 내려놓은 자의 유일한 고백 (눅 18:35-43)
- **βιάζεται (침입)**: 자기 의를 스스로 깨뜨리고 그리스도의 의를 붙잡아 들어가는 것 (눅 16:14-18)
- **귀환**: 문제 해결이 아닌 예수 그리스도에게로 돌아가는 것 = 근원적 해결 (눅 17:11-19)
- **ἀναβλέπω (다시 봄)**: 육안의 눈이 닫히고 그리스도를 보는 영적 눈이 열림 (눅 18:35-43)
- **약함으로 나아감**: 약함이 하나님의 강한 손을 움직이는 힘 (출 6:1-7)
- **그리스도의 이름**: 내 이름(자기 의)이 아닌 그리스도의 이름으로만 하나님 앞에 설 수 있음 (눅 16:14-18b)
- **십자가 = 하나님의 맞음 포기**: 하나님이 먼저 자기 맞음을 십자가에 내려놓으심 → 우리도 동참 (눅 18:24-30)
- **마지막 결정권자 이양**: 내가 왕 → 그리스도가 왕 = 벳파게에서 베다니로 (눅 19:28-40)
- **기도 = 말씀에 매달림(ἐκκρεμάννυμι)**: 자기 요구 목록이 아니라 말씀에 붙들려 변화됨 = 교회의 본질 회복 (눅 19:45-48)
- **에이레네(εἰρήνη)**: 왕을 받아들이는 자에게 주어지는 영원한 평화 (눅 19:41-44)
- **이끌려가는 삶**: 새 기준을 내가 잡으면 더 교묘한 바리새인이 됨 — 예수 그리스도라는 기준에 의존·사로잡힌 상태 (눅 20:1-8)
- **새로운 갈망**: "내 안에 이 형상이 지워지고 하나님의 형상이 살아나기를 원합니다" = 성령의 역사 시작 (눅 20:19-26)
- **인생의 주제 전환**: "무엇이 나의 소유인가" → "나의 주인은 누구인가 / 나는 누구의 것인가" (눅 20:19-26)

## 세 부류의 인간 (눅 16:19-21 구조)

| 부류 | 상태 | 결과 |
|---|---|---|
| **부자 (바리새인)** | 자기 의로 자기를 잔치함 — 잃은 적 없다고 여김 | 자기 맞음을 끝까지 붙잡음 → 음부 확정 |
| **나사로 (세리·탕자)** | 거지임을 앎 — 말씀(부스러기) 받아먹음 → ἕλκος | 실체 이미 드러남 → 다시 봄 → 하나님 나라 |
| **개들 (형식주의자)** | 회개했다 죄의 자리로 돌아가 핥아 먹음 | 자기 운영 체계 안으로 다시 잠김 |

## 실천적 자기 진단

1. **나의 ᾅδης는 무엇인가?** 아직 한 번도 드러난 적 없는 내면의 실체가 무엇인가? (눅 16:22-23)
2. **나는 부자인가 나사로인가?** 나는 자기 의를 잔치하는가, 거지임을 아는가? (눅 16:19-21)
3. **나의 락은 무엇인가?** 어떤 자기 언어·철학으로 심장이 잠겨 있는가? (눅 16:27-31)
4. **나의 운영 체계는 무엇인가?** 내가 보는 것이 진실인가, 내 OS의 해석인가? (눅 18:31-34)
5. **나는 "내가 맞다"가 얼마나 많은가?** 자기 의의 축적이 나를 얼마나 부자로 만들었는가? (눅 18:24-30)
6. **나의 뽕나무는 무엇인가?** 관계에서 반복되는 실족의 근원은 어디인가? (눅 17:1-10)
7. **나는 안에 있는가 바깥에 있는가?** 내가 질문하는가, 하나님께 질문받는가? (눅 18:9-14)
8. **나는 무엇을 붙잡고 있는가?** "이것을 잃으면 나는 끝이다"고 느끼는 것은 무엇인가? (눅 17:30-37)
9. **양심 앞에서 나는 어디에 서 있는가?** 양심이 무엇을 고발하는가? (눅 18:35-43)
10. **나는 주인인가 청지기인가?** 내 삶의 소유권이 누구에게 있는가? (눅 20:9-18)
11. **나는 강함을 추구하는가 약함을 인정하는가?** (출 6:1-7)
12. **나의 마지막 결정권자는 누구인가?** 돈·감정·이해관계 순간에 최종 결정하는 자가 나인가, 그리스도인가? (눅 19:28-40)
13. **내 눈의 확증 편향은 무엇인가?** 내가 보고 싶은 것만 보이도록 잠긴 세계가 있는가? 그 세계에 금이 가기 시작했는가? (눅 19:41-44)
14. **나는 말씀에 붙들려 매달리는가, 도피처로 삼는가?** 교회가 내게 삶의 변화를 일으키는 곳인가, 안심만 확인받는 곳인가? (눅 19:45-48)
15. **나의 자기 기준은 무엇인가?** 어떤 분리 불안·생존 불안에서 그 기준이 만들어졌는가? 그 기준이 공격받을 때 나는 바꾸는가, 방어하는가? (눅 20:1-8)
16. **내 욕망은 누가 설계했는가?** 내가 욕망하는 것, 두려워하는 것, 신경 쓰는 것이 알고리즘·돈·인정인가 하나님인가? 나는 가이사의 것인가 하나님의 것인가? (눅 20:19-26)
17. **나는 누구이고 싶은가?** "나는 누구인가"(과거·환경·현재 상태)로 자신을 규정하는가, "나는 누구이고 싶은가"(하나님이 부르신 이름·미래·비전)로 이끌리는가? (엡 1:3-12)
18. **나는 지금 길 위에 있는가?** 뜻이 없어서 멈추어 있는가, 아니면 일단 길을 가고 있는가? "한 발자국도 안 가고 이러면 안 돼 저러면 안 돼 하는가?" 예수 그리스도라는 길 위에 있으면 뜻은 따라온다. (엡 1:3-12 / 요 14:6)
19. **내 인생의 동력은 무엇인가?** 노력과 의지로 버티는가, 하나님이 나를 향해 가지신 기쁘신 뜻을 알아 기쁨과 설렘으로 살아가는가? (엡 1:5 / εὐδοκία)
