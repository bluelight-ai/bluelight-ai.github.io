## 개요
선한목자병원 주일예배 설교 3편은 각각 다른 본문에서 출발하지만, 하나의 신학적 핵심으로 수렴한다:

> **인간은 자기 삶의 주인이 될 수 없으며, 자기 기준·자기 의·자기 소유권을 내려놓고 하나님께 항복하는 것이 구원이다.**

## 세 설교의 구조 비교

| 항목 | 마태복음 6:19-24 | 누가복음 20:9-18 | 누가복음 18:18-23 |
|---|---|---|---|
| **문제** | 잘못된 OS(운영체계) | 소유권 탈취 시도 | 자기 의의 기준 |
| **인간의 착각** | 땅의 보물이 진짜 보물 | 내가 포도원의 주인 | 행함으로 선함에 도달 가능 |
| **하나님의 응답** | OS 전체를 교체하라 | 머릿돌과의 충돌 | 더 높은 절대 기준 제시 |
| **전환의 내용** | 선악 OS → 은혜 OS | 주인됨 포기 → 회개 | 자기 의 포기 → 그리스도의 의 |
| **결과(긍정)** | 하늘에 쌓은 보물 | 머릿돌 위에 깨어짐(구원) | 하늘의 보화 |
| **결과(부정)** | 두 주인 섬김 → 파멸 | 머릿돌에 짓눌려 소멸 | 자기 기준으로 하나님 앞에 서면 무효 |

## 공통 신학 구조: 3단계 운동

### 1단계 — 인간의 착각 (자기 주인됨)
세 설교 모두 인간이 스스로 주인이 되려는 근본 문제를 진단한다.
- **마태복음**: 마음이 땅의 보물에 붙어 눈이 어두워짐 → 잘못된 OS 작동
- **누가복음 20장**: 농부들이 포도원을 자기 것으로 여기고 아들까지 죽임
- **누가복음 18장**: 관리가 행함으로 선함을 '관리·통제'해 영생에 도달하려 함

→ **공통 뿌리**: 인간은 자기를 만들지 않았고, 미래를 통제할 수 없고, 죽음을 해결할 수 없다. 그럼에도 주인이 되려 한다. ([[nt-studies/anon-2026-luke-20-9-18-inevitable-collision]] 참조)

### 2단계 — 충돌 (하나님의 기준이 드러남)
- **마태복음**: 하나님의 은혜 OS vs 인간의 자기 의 OS — 두 주인을 섬길 수 없음
- **누가복음 20장**: 머릿돌(그리스도)과의 피할 수 없는 운명적 충돌
- **누가복음 18장**: "하나님 외에 선한 이 없다" — 절대 기준의 출현으로 자기 기준 무효화

→ **공통 패턴**: 하나님의 기준은 인간의 기준보다 무한히 높다. 충돌은 피할 수 없다.

### 3단계 — 전환 (항복과 은혜)
- **마태복음**: 선악 OS 삭제, 은혜 OS 재설치 = 거듭남
- **누가복음 20장**: 머릿돌 위에 떨어져 '내 주인됨'이 깨어짐 = 회개
- **누가복음 18장**: 자기 의를 팔아 가난한 자가 되어 그리스도의 의를 받음 = 구원

→ **공통 결론**: 전환은 부분적 행동 수정이 아닌 **전인적 항복**이다.

## 핵심 개념 연결망

```
자기 주인됨
    ├── 자기 보물 (마 6)        → 땅에 쌓음 → OS 오염
    ├── 자기 소유권 (눅 20)     → 포도원 탈취 → 아들을 죽임
    └── 자기 의 (눅 18)         → 행함으로 선함 도달 시도

          ↓ 충돌 (피할 수 없음)

그리스도 = 머릿돌 = 절대 기준 = 하나님의 OS

          ↓ 두 가지 결과

    깨어짐 (회개·항복)          소멸 (심판)
    └── 하늘의 보화             └── 가루처럼 흩어짐
    └── 은혜 OS 작동            └── 자기 기준으로 영원히 판정
    └── 하나님이 주인           └── 자기가 주인인 채 멸망
```

## 실천적 함의
1. **자기 진단**: 나는 무엇을 보물로 여기는가? (마 6) 나는 무엇의 주인이라고 착각하는가? (눅 20) 나는 어떤 기준으로 스스로를 의롭다 하는가? (눅 18)
2. **충돌 수용**: 말씀과 충돌할 때 깨어지는 쪽을 선택하라 (눅 20)
3. **기준 전환**: 자기 의를 내려놓고 그리스도의 의를 받아들이는 것은 일회적 사건이자 지속적 태도다
