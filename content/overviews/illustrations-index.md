## 개요

이 시리즈에서 사용된 예화와 비유를 유형별로 정리한 색인이다. 설교 준비, 소그룹 나눔, 개인 묵상에서 원하는 예화를 빠르게 찾을 때 사용한다. 각 예화 뒤에 **핵심 신학 포인트**와 **해당 설교 링크**를 표기했다.

## 인물 예화

### 역사적 인물

| 예화 | 핵심 포인트 | 설교 |
|---|---|---|
| **헬렌 켈러** — 1887년 4월 5일 우물가. 물(촉각) + WATER(이름) = 의미 탄생. 수백 개 단어를 몇 주 만에 습득 | 느낌 + 이름 = 의미. 하나의 해석 전환이 모든 것을 바꿈 = 근원 경험의 교육 모형 | [[nt-studies/anon-2026-acts-9-10-22-interpretation-life-peak-meaning]] |
| **닉부이치치** — 사지 없이 태어남. 세 번 자살 시도 → "하나님은 누구도 실수로 만들지 않으신다" → 87개국 강연자 | 팩트는 동일, 해석이 바뀌면 인생이 달라짐 | [[nt-studies/anon-2026-acts-9-1-22-new-life-four-processes]] |
| **김선도 감독 (광림교회)** — 6·25 전쟁 중 따발총 병사 옆에서 기도, 5분 만에 남한군 군의관으로 전환 → 그 5분으로 90년 인생 전체를 해석 | 5분의 기적 = 하나의 경험이 인생 전체의 의미를 통합하는 모형 | [[nt-studies/anon-2026-acts-9-10-22-interpretation-life-peak-meaning]] |
| **마틴 루터** — 10년 자기 의 추구 → 지옥 같은 마음 → 로마서 1:17 → 천국의 문. "이제야 천국의 문이 열렸다" | OS 전환, 자기 의에서 그리스도의 의로 = 다시 봄(ἀναβλέπω) | [[nt-studies/anon-2026-luke-18-35-43-blind-jericho-see-again-conscience]] |
| **타이거 우즈** — 기존 스윙폼("맞다") 포기 → 새 OS 탑재 → 메이저 6회 추가 우승 | "내가 맞다"를 내려놓아야 새 OS를 받을 수 있음 | [[nt-studies/anon-2026-luke-18-24-30-camel-needle-self-right-impossible]] |
| **비르길 / 프라카슈** — 선천성 백내장 수술 후 시력 회복했지만 볼 수 없음. 뇌가 시각 OS를 형성하지 못했기 때문 | 보는 것은 눈이 아니라 운영 체계(OS)가 봄 | [[nt-studies/anon-2026-luke-18-31-34-seeing-not-seeing-operating-system]] |
| **요한 슬레의 묘비** — "이 세상에서 가장 좋은 것은 하나님이 우리와 함께 하심이라" | 해석 체계 전환의 종착점: "나는 누구인가"가 아닌 "하나님이 나와 함께 하시는가" | [[nt-studies/anon-2026-acts-9-1-22-new-life-four-processes]] |
| **에비슨·로제타 홀** — 조선에서 사역한 선교사들. 값을 계산하고 모든 것을 버림 | 무리·제자·종의 구분 = 값을 계산한 자 | [[nt-studies/anon-2026-luke-14-25-35-cost-calculation-disciple-servant]] |
| **존 고트먼 박사** — 부부 관계 연구. 비판·방어·경멸·담쌓기 = 이혼 예측 4가지 | 자기 의의 축적이 관계를 파괴함 | [[nt-studies/anon-2026-luke-18-24-30-camel-needle-self-right-impossible]] |
| **김해영 선교사** — 구체적 사역 변화 사례 | 삶에 존재하는 방식의 전환 | [[nt-studies/anon-2026-acts-9-1-22-new-life-four-processes]] |

| **삭개오 이름 역설** — 삭개오(순결한 자)가 세리장·죄인. 예수님이 찾아오시자 이름의 뜻이 현실이 됨 | 하나님이 부르신 이름 = 진짜 정체성 | [[nt-studies/anon-2026-luke-19-1-10-zacchaeus-descent-grace-revolution]] |
| **엘리야·까마귀·사르밧 과부** (왕상 17장) — 바알=비의 신 착각 → 하나님이 비 3년 반 끊음 → 까마귀가 엘리야를 먹임 → 사르밧 이방 과부가 마지막 것을 줌 → 기름 끊이지 않음 | 보편 은총이 특별 은총을 섬김. 보편 은총 < 특별 은총 | [[nt-studies/anon-2026-matt-6-25-34-solomon-glory-special-grace]] |
| **스데반의 순교 → 사울의 균열** — 스데반의 빛나는 얼굴·용서의 기도가 사울의 신학 체계에 금을 냄 | 균열 = 하나님이 먼저 일하시는 것 = 근원 경험으로 이끄시는 은혜 | [[nt-studies/anon-2026-acts-9-10-22-interpretation-life-peak-meaning]] |

## 개념 비유

| 비유 | 핵심 포인트 | 설교 |
|---|---|---|
| **테세우스의 배 역설** — 모든 부품이 교체된 배는 원래 배인가? (플루타르코스) | 인간에게 변하지 않는 고유한 본질은 없음 | [[nt-studies/anon-2026-eph-1-3-12-great-mindset-special-people]] |
| **닭(운영체계) vs 계란(출력)** — 닭이 먼저 있어야 계란이 계속 나옴. 뜻=계란, 길=닭 | 길이 먼저, 뜻은 나중. "뜻이 있으면 길이 있다"는 역방향 | [[nt-studies/anon-2026-eph-1-3-12-great-mindset-special-people]] |
| **뱀 vs 꿀벌** — 같은 물이라도 뱀은 독으로, 꿀벌은 꿀로 만듦 | 팩트는 동일, 해석 체계가 결과를 결정함 | [[nt-studies/anon-2026-acts-9-1-22-new-life-four-processes]] |
| **떨기나무 신학** (출 3장) — 쓸데없는 떨기나무에 불이 붙었지만 타지 않음 | 나(떨기나무) + 그리스도(불꽃) = 소멸되지 않는 존재 = 십자가 구조 | [[nt-studies/anon-2026-acts-9-1-22-new-life-four-processes]] |
| **락(Lock)** — 자기 철학·자기 언어로 심장을 잠가버림 | 완벽하게 잠긴 해석 체계 = 죽은 자가 살아나도 안 믿음 | [[nt-studies/anon-2026-luke-16-27-31-self-locked-heart-recoding]] |
| **병뚜껑** — 아무리 좋은 것을 부어도 뚜껑이 닫혀 있으면 들어가지 못함 | 은혜가 들어가지 못하는 구조 = 카스마(구렁텅이) | [[nt-studies/anon-2026-luke-16-23-26-grace-cannot-enter-structure]] |
| **곰팡이 예화** — 같은 곰팡이 속 사람끼리는 서로 정상인 줄 앎. 새 바람이 필요 | 자기 운영 체계 안에서는 자기 문제를 볼 수 없음 | [[nt-studies/anon-2026-luke-16-22-23-death-reveals-reality-hades]] |
| **개미와 돌** — 개미가 돌을 옮기려 하면 자기 의 = 0이 됨 | 자기 의 0이 되어야 전적 은혜가 들어옴 | [[nt-studies/anon-2026-luke-16-1-7-unjust-steward-self-righteousness-zero]] |
| **솔로몬 콤플렉스** — SNS·유튜브가 욕망을 해킹하여 상위 1%와 비교하게 만듦 | 이방인의 욕망 구조 = 문명이 설계한 욕망 | [[nt-studies/anon-2026-matt-6-25-34-solomon-glory-special-grace]] |
| **ChatGPT 예화** — "일단 뭐든지 만들어 봐라" → 가다 보니 뜻이 보임 | 길이 먼저, 뜻은 나중의 실전 사례 | [[nt-studies/anon-2026-eph-1-3-12-great-mindset-special-people]] |
| **벳파게 vs 베다니** — 먹을 수 없는 무화과(열매 없음) vs 두 번째 무화과(열매 있음) | 왕을 거부하는 자 vs 왕을 받아들이는 자 = 마지막 결정권자 | [[nt-studies/anon-2026-luke-19-28-40-king-entry-final-authority]] |
| **만몬(Mammon)** — 내가 쌓은 보물이 내 믿음의 대상이 되는 순간 주인이 됨 | 재물이 주인이 되는 구조 = 눈이 어두워진 결과 | [[nt-studies/anon-nd-matthew-6-19-24-os-transition]] |
| **분리 불안** — 탄생 = 엄마와의 첫 분리 = 인간 최초의 근원 경험 → 생존 불안 → 기준 형성 | 자기 기준의 심리적 기원 | [[nt-studies/anon-2026-luke-20-1-8-self-standard-blocks-sight]] |
