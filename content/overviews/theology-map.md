## 개요

이 지도는 39편 설교가 하나의 신학적 논증 안에서 어떤 위치를 차지하는지 보여준다. 전체 시리즈는 **탕자의 4단계 여정** 구조로 읽히며, 각 설교는 그 여정의 특정 지점을 깊이 파고든다.

---

## 전체 구조 개요

```
인간의 문제                           하나님의 해결
─────────────────────────────────────────────────────

1단계: 독립 선언    2단계: 충돌        3단계: 각성        4단계: 전환
자기 의로 왕이 됨  하나님 기준과 만남  밑바닥에서 돌이킴  그리스도의 의를 받음
     │                  │                  │                  │
  (눅 15:11-12)    (눅 18:18-23)      (눅 15:17)         (눅 15:20)
     │                  │                  │                  │
  누가복음 전반     누가복음 중반       누가복음 후반       사도행전·에베소서
```

## 시리즈 간 연결 구조

```
출애굽기 6장        마태복음 6장          에베소서 1장
(약함의 신학)  ←→  (은총의 계층)   ←→  (새로운 사고방식)
     │                  │                    │
     └──────────────────┼────────────────────┘
                        │
             사도행전 9장 (전환의 과정)
                        │
             누가복음 14-20장 (자기 의 해체 여정)
```

**각 시리즈의 역할**:
- **누가복음 14-20장**: 자기 의가 무엇인지, 어떻게 해체되는지 — 문제와 과정
- **사도행전 9장**: 실제 변화가 어떻게 일어나는지 — 전환의 메커니즘
- **에베소서 1장**: 변화된 인간이 어떻게 생각하는지 — 새로운 사고방식
- **마태복음 6장**: 변화된 인간이 세상과 어떻게 관계 맺는지 — 실전 적용
- **출애굽기 6장**: 전환의 조건 — 약함과 신음

## 새 설교 배치 기준

새 설교를 추가할 때 이 4단계 중 어디에 해당하는지 판단한다:

| 단계 | 해당 내용 |
|---|---|
| 1단계 (독립 선언) | 자기 의의 새로운 형태, 자기 주인 됨의 메커니즘 |
| 2단계 (충돌) | 진리와 자기 의의 충돌, 하나님의 기준 폭로 |
| 3단계 (각성) | 밑바닥 경험, 균열, "주여 나를 불쌍히 여기소서" |
| 4단계 (전환) | 귀환, 새로운 정체성, 삶의 변화 |
| 교차 | 4단계 전체를 아우르는 설교 |
