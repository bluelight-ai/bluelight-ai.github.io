## 요약
누가복음 17:11-19 열 나병환자 본문은 감사가 아닌 **귀환**을 주제로 한다. 10명 모두 나병이 나았지만 9명은 종교 시스템(제사장)으로 돌아갔고, 사마리아인 1명만 예수님께로 귀환하여 구원을 얻었다. 문제 해결과 귀환은 다르다. 인생의 모든 문제(나병·집·직장·몸)를 해결해도 남는 근원적 공허함의 해결은 오직 예수 그리스도에게로의 귀환이다.

## 핵심 주장

### 귀환 (歸還) — 본문의 진짜 주제
> 귀환 = 내가 본래 있어야 될 자리로 돌아가는 것

나병 치유의 목적(레위기 13-14장):  
나병 완치 → 제사장 확인 → 공동체 복귀 → **하나님께 예배드리는 자리로 복귀**

즉 나병 치유 자체가 목적이 아니라, 하나님께로 나아가는 것이 목적이다.

### 9명과 1명의 분기점

| | 9명 (유대인) | 1명 (사마리아인) |
|---|---|---|
| **치유 여부** | O | O |
| **귀환 방향** | 제사장 시스템 → 공동체 | 예수님께로 |
| **논리** | 나병 치유 = 제사장이 하나님께 나아가는 길 | 나를 고치신 분 = 하나님께 나아가는 그 자리 |
| **결과** | 치유O, 구원X | 치유O, 구원O |
| **예수님 판결** | "그 아홉은 어디에 있느냐" | "네 믿음이 너를 구원하였느니라" |

### 지리적 상징: 사마리아와 갈릴리 경계
- 갈릴리 = 유대 공동체 쪽 (하나님 나라 공동체 안)
- 사마리아 = 이방인 (공동체 밖)
- **경계**에 있는 나병환자 집단 = 공동체 안과 밖 모두에서 버림받은 자들
- 역설: 공동체 바깥의 사마리아인이 진짜 귀환을 이루고, 공동체 안의 유대인 9명은 귀환하지 못함

### 문제 해결 ≠ 귀환: 인생 문제의 연쇄

```
5살: 사탕 문제
10대: 공부 문제
20대: 직장·결혼 문제
30-40대: 집 문제
노년: 몸·건강 문제
죽을 때: 죽음 문제
```

한 문제가 해결되면 잠깐 안도하지만 다음 문제가 온다. 문제 속에 살다가 문제 속에서 죽는다. 그러나 어떤 사람은 이 모든 문제의 **근원**을 끊어내는 본질을 발견한다 → 예수 그리스도에게로 귀환.

### 현대 적용: 문제가 해결되어도 남는 공허함

| 문제 해결 사례 | 해결 후 현실 |
|---|---|
| 인공관절 수술로 다리 통증 제거 | 이제 걸을 수 있는데 내가 어디로 걸어가는 건지 모름 |
| 월세→자가→임대인 | 임대인이 되어도 마음의 평안 없음 |
| 자녀 양육에 최선 | 자녀와의 관계는 여전히 해결 안 됨 |
| 교회 봉사·십일조·새벽예배 | 구원의 임재·평안 없음 |

**공통 진단**: 문제는 해결되었으나 귀환되지 않음 — 종교 시스템으로 돌아간 9명과 같음.

## 귀환의 신학: 하나님께로 나아가는 유일한 길

다른 종교들의 답: "착하게 살아라" / "계율을 지켜라" — 창조주께 나아가는 길을 개시(啓示)하지 못함.

복음의 답:
> "길과 진리와 생명이신 예수 그리스도를 통하지 않고는 아무도 아버지께로 올 수 없다" (요 14:6)

창조주 하나님을 만날 수 있는 유일한 자리 = 예수 그리스도에게로의 귀환.  
이것이 인생의 모든 문제를 넘어서는 근원적 해결이다.
