## 요약
바리새인들이 "돈을 좋아한다"는 표현은 현찰 탐욕이 아니라 **자기 행위로 만든 가치(자기 의)를 소중히 여기는 것**이다. 이것은 자기 우상숭배이며 하나님이 가장 미워하신다. 예수 그리스도 안에서 자기 의가 파괴될 때, 그 파괴가 하나님 나라로 **침범해 들어가는** 문이 된다.

## 핵심 주장

### 1. "돈" = 자기 의

> φιλάργυρος = 은(銀)을 사랑하는 자 → **자기가 만들어낸 가치를 소중히 여기는 자**

- 은 = 인간이 주도해서 만들어낸 가치 = 돈
- 바리새인의 돈 사랑 = 자기 행위로 쌓은 의(율법·성전·제사·금식)를 재물로 여기는 것
- 현찰 탐욕이 아니라 **자기 만든 것의 가치를 인정받으려는 구조**

### 2. 자기 의의 보편성

**"너 나빠" vs "너 틀렸어":**
- "너 나빠" → 별로 기분 안 나쁨
- "너 틀렸어" → 존재가 해체되는 것 같은 고통

이유: **자기가 만든 가치(자기 의)가 부정되는 것 = 존재 해체**

| 예화 | 자기 의의 구조 |
|---|---|
| 짜장면 선택 후 맛없어도 → "이 집이 문제" | 자기 선택이 틀렸다는 걸 인정 못함 |
| 시험: 내가 문제 내고 내가 채점 → 100점 | 자기가 기준, 자기가 채점자 |
| 80억 인구 모두 자기 판단 기준 | 존재 구조적 자기 의 |

### 3. 15절 — 사람 앞에서 자기 의 세우기

> "너희는 사람 앞에서 스스로 옳다 하는 자들이나 너희 마음을 하나님이 아시나니"

- 하나님 앞에서 인정받을 수 없는 자기 의 → **사람 앞으로 방향 전환**
- 경건한 기도·십일조·선한 일·공감 = 사람 앞에서 자기 의를 전시하는 행위
- **"사람 중 높임 = 하나님 앞 미움"**

### 4. 자기 의 = 자기 우상숭배

```
구약 우상숭배 = 금송아지 등 형상을 만들어 섬김
              ↕ 본질
자기 의 세우기 = 자기가 옳다는 것을 행위로 형상화하여 섬김
              = 자기를 섬기는 것
              = 하나님이 가장 미워하시는 것
```

### 5. 16절 — 율법 → 복음 → 침입

> "율법과 선지자는 요한의 때까지요 그 후부터는 하나님 나라의 복음이 전파되어 사람마다 그리로 침입하느니라"

**율법과 선지자 → 예수 그리스도:**
- 구약의 모든 계시·언약이 예수 그리스도 안에서 실체화·완성됨
- 자기 의의 껍데기로 쌓아 올린 모든 것이 십자가에서 완전히 파괴됨

**"침입"(βιάζεται)의 바른 해석:**
- 오해: 하나님 나라를 폭력으로 빼앗음
- **바른 해석: 자기 의를 강도처럼 쳐들어가 부서뜨리는 것 → 하나님 나라로 들어감**
- 복음이 전파되어 자기 의가 파괴되는 사람들이 하나님 나라로 들어가는 시대 개막

### 6. 의의 기준 전환 — 구원의 핵심

```
자기 의 기준 (내가 문제 내고 내가 채점)
    ↓ 예수 그리스도 안에서 파괴
    ↓ "내가 틀렸습니다" = 존재 해체의 고통
그리스도의 의 기준 (하나님이 인정하시는 의)
    ↓
하나님 나라로 침범해 들어감
```

- 의의 기준이 바뀌는 순간 = 구원의 문이 열리는 순간
- 이것이 15-16장 전체 논증(탕자·불의한 청지기·바리새인 비판)의 결론

## 15-16장 전체 논증 완성

```
15:1-7   잃은 양        → 1(상하고 통회) vs 99(자기 의)
15:8-10  잃은 드라크마   → 죄=분리, 회개=찾아짐
15:11-19 탕자 전반      → 독립 선언·흉년·밑바닥·각성
15:20-32 탕자 귀환·큰아들 → 돌아온 탕자(0) vs 돌아오지 않은 큰아들(자기 의)
16:1-7   불의한 청지기   → 재물=자기 의, 100→80·50 (0에 이르지 못함)
16:8-14  청지기 결론    → 작은 것(자기 의) 버려야 큰 것(그리스도 의), 배설물
16:14-18 바리새인 조롱  → 돈=자기 의, 자기 우상숭배, 침입=자기 의 파괴, 의의 기준 전환
```
