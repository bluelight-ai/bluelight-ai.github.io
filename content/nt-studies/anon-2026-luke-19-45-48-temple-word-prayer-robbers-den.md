## 요약
성전의 본질은 만민이 기도하는 집(이사야 56장)이지만 삶의 변화 없이 도피처로 삼으면 강도의 소굴(예레미야 7장)이 된다. 기도의 정의는 47-48절이 직접 보여준다: 예수 그리스도의 말씀에 사로잡혀 붙들리고 매달리는 것(ἐκκρεμάννυμι). 이 말씀 운동이 끊어질 때 교회는 신뢰를 잃고 강도의 소굴이 된다.

## 핵심 주장

### 1. 두 구약 본문 합성

**이사야 56장** — 성전의 본질:
```
바벨론 포로 후 회복: 환관·이방인 포함 모든 백성
= 내 집은 만민이 기도하는 집이 될 것이다
```

**예레미야 7장** — 성전의 타락:
```
소굴(=도피처): 죄 짓고 와서 제사 → "죄사함 받았다" → 나감
= 강도들이 안전을 확인받는 도피처
```

### 2. 강도의 소굴 = 도피처

- 죄를 짓고 성전에 와서 제사를 드리며 죄사함을 확인받고 변하지 않음
- 현대: 교회 출석 + 눈물 + "피로 사해주소서" + 삶 변화 없음 = 동일한 구조
- 세상의 평가: "말로만 예수, 삶은 강도" = 예수님의 "강도의 소굴" 평가와 일치

### 3. 두 반응 — 47-48절

**종교 지도자들**: 강도의 소굴 구조에서 권력·명예를 탐닉하던 자들 → 구조를 끊는 진리에 예수님을 죽이려 꾀함

**백성들**: ἐκκρεμάννυμι — "말씀에 붙들려 매달린 상태"
- 설교를 평가하는 것이 아님
- 예수님의 말씀에 사로잡혀 완전히 매달린 상태

### 4. 기도의 정의

```
만민이 기도하는 집 (45절의 본질)
+
ἐκκρεμάννυμι (47-48절이 보여주는 실체)
↓
기도 = 예수 그리스도의 말씀에 사로잡혀 붙들리고 매달리는 것
      말씀 선포 → 말씀에 깨짐 → 말씀대로 되게 해달라고 매달림
```

### 5. 한국 교회 신뢰도

| | 수치 |
|---|---|
| 기독교 인구 | 18% (감소 중) |
| 무종교 | 60% |
| 개신교 신뢰도 | 35.4% (꼴찌, 불교·천주교보다 낮음) |

원인: 진리 없이 배타적, 설득력 없는 전도, 자기 중심적 = 강도의 소굴화

### 6. 교회 선택의 기준

**잘못된 기준**: 맛집처럼 설교 미리 들어보고 입맛에 맞으면 선택, 유튜브 예배로 대체

**올바른 기준**:
> "저 목사님의 말씀이 성경 본문에서 말하고자 하는 진짜 예수님의 말씀을 정말로 찾아서 전하고 있는가?"

### 7. 부흥 = 말씀 운동

| 운동 | 핵심 |
|---|---|
| 에스라의 종교 개혁 | 말씀 선포 → 백성이 울며 매달림 |
| 루터·칼빈의 종교 개혁 | 성경 진리 선포 |
| 요한 웨슬리 | 말씀 선포 + 소그룹 나눔 |

**엘리 시대** (삼상 3:1): "하나님의 말씀의 이상이 희귀하여 더 이상 들리지 않는 시대" = 말씀이 끊어진 교회의 위기

## 주요 용어
- **만민이 기도하는 집**: 이사야 56장 — 모든 백성이 하나님의 집에서 기도하는 곳 = 성전의 본질
- **강도의 소굴(도피처)**: 예레미야 7장 — 삶 변화 없이 제사로 도망치는 구조 = 성전의 타락
- **ἐκκρεμάννυμι**: 누가복음 19:48 — "귀를 기울여 들으므로"의 원어 = "말씀에 붙들려 매달린 상태"
- **기도의 정의**: 말씀에 사로잡혀 붙들리고 매달리는 것 (간구 목록이 아님)
- **부흥 = 말씀 운동**: 역사적 부흥은 모두 말씀 선포 + 성도의 매달림
- **엘리 시대**: 말씀의 이상이 희귀해진 시대 = 교회 위기의 본질
