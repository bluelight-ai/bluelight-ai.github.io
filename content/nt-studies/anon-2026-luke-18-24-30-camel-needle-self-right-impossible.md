## 요약
부자가 하나님 나라에 들어가지 못하는 이유는 재물 자체가 아니라 "내가 맞다"는 자기 의의 구조가 많기 때문이다. 집·아내·부모·형제·자녀를 버린다는 것은 나를 지탱하던 모든 존재 기반(내가 맞다는 구조)을 해체하는 것이다. 하나님은 십자가에서 자신의 맞음을 먼저 포기하셨고, 우리도 자기 맞음을 십자가에 함께 못 박을 때 은혜의 문이 열린다.

## 핵심 주장

### 1. "내가 맞다" 대 "내가 맞다" — 싸움의 구조

- 틀린 것과 맞는 것은 싸우지 않는다 — 틀린 쪽이 인정하면 끝
- 싸움이 나는 이유: **맞다 대 맞다** = 둘 다 옳다고 여기기 때문
- 부자 관원의 질문("내가 뭘 더 해야 영생을 얻으리이까")은 예수님께 자기 맞음을 더욱 공고히 하려는 시도
- 예수님: "네가 맞다고 여긴 것을 다 팔아 가난한 자에게 줘라" = 너 틀리다
- 근심하며 돌아감 = **그래도 내가 맞다는 것을 포기할 수 없음**

### 2. 낙타·바늘귀 = "내가 맞다"가 많은 자의 구조적 불가능

- **부자 = 내가 맞다는 게 많은 자**
- 낙타가 바늘귀로 들어갈 수 없듯, 자기 의가 많은 자는 하나님 나라에 구조적으로 들어갈 수 없음
- 듣는 자들: "그런즉 누가 구원을 얻을 수 있나이까?"
- 예수님: "사람으로는 할 수 없으되 하나님으로서는 하실 수 있느니라"

### 3. 사람 불가·하나님 가능의 신학

```
하나님 나라 = 행위·성취가 아닌 하나님의 은혜로 들어가는 세계
은혜를 받을 수 없는 자: 내가 맞다가 많은 자 (부자)
은혜를 받는 자: 내가 맞다는 구조가 무너져 "아무것도 맞는 게 없다"는 자
```

하나님이 구원하시는 방식: 맞다고 살던 자를 붙들어 → 맞다는 구조를 무너뜨린 다음 → 비워진 자에게 은혜로 들어감

### 4. 집·아내·부모·형제·자녀 버리기 = 자기 존재 기반 해체

| 버리는 것 | 상징하는 기반 |
|---|---|
| 집 | 존재 기반 |
| 아내 | 관계성의 기반 |
| 부모 | 기원의 기반 |
| 형제 | 공동체적 기반 |
| 자녀 | 미래·성취의 기반 |

= **나를 존재하게 붙들고 있는 모든 기반 = 내가 맞다는 구조 전체**

이 기반들을 위해 쌓는 것 → "내가 맞다" 구조 강화. 버리기 = 이 모든 관계·존재 시스템을 깨고 하나님 나라의 존재 기반으로 바뀌는 것.

### 5. 타이거 우즈 예화 — 기존 맞음을 버려야 새 구조를 받아들일 수 있음

- 1997년~: PGA 9회 우승, 메이저 3개 석권 → 정점
- 결단: "지금 스윙폼으로는 더 나은 구조로 나갈 수 없다" → 자기 맞다는 폼 포기
- 새 코치 + 수년 연습 → 2003-2004년 우승 없음 → 평범한 선수
- 새 폼 완성 후 → **메이저 6번 우승**

> 내가 새로운 시스템(하나님 나라)을 받아들이려면, 내가 맞다고 여기는 구조가 먼저 깨져야 한다.

### 6. 존 고트먼 예화 — 내가 맞다를 내려놓는 자가 관계를 유지함

- 미국 심리학자 존 고트먼: 40년간 3,000쌍 부부 연구
- 5분만 들으면 이혼 여부 90% 예측
- **이혼으로 가는 4대 언어**: 비난 / 방어 / 경멸 / 담 쌓기
- 부부 갈등의 **69%는 평생 해결 불가** (성격·말투·습관 등)
- 평생 함께 가는 부부: 갈등이 있어도 **내가 맞다는 자기 기준을 내려놓은 부부**

### 7. 십자가 = 하나님이 자기 맞음을 먼저 포기하신 사건

```
맞다 대 맞다 상황 → 관계 불가능
↓
하나님이 먼저 하신 것:
율법·성전·제사·계명의 기준 → 십자가에 못 박음
= 하나님이 자기 맞음을 스스로 내려놓으심
↓
우리가 할 것:
나의 맞음도 십자가에 함께 못 박음
= 사람으로는 할 수 없으나 하나님으로서는 하실 수 있는 은혜의 세계가 들어옴
```

## 주요 용어
- **내가 맞다**: 자기 의의 구조 — 부자의 본질, 하나님 나라 입장을 가로막는 것
- **낙타·바늘귀**: 자기 의가 많은 자는 구조적으로 하나님 나라에 들어갈 수 없음
- **존재 기반**: 집·아내·부모·형제·자녀 = 나를 지탱하던 모든 기반 = 내가 맞다는 구조
- **사람 불가·하나님 가능**: 자기 의의 구조는 스스로 깰 수 없음 — 하나님의 은혜만이 가능
- **십자가 = 하나님의 맞음 포기**: 하나님이 먼저 자기 맞음을 내려놓으심으로 은혜의 길을 여심
