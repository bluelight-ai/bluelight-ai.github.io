## 요약
잃은 양 하나와 99마리의 대비는 단순한 숫자가 아니라 심령의 상태를 상징한다. **1(잃은 양)** = 자기 의가 없어 상하고 통회하는 심령. **99** = 자기 의로 꽉 차서 회개할 것이 없다 여기는 바리새인적 상태. 하나님은 99를 *버리고* 1을 기필코 찾아내어 당신의 명예와 천국 잔치로 이끄신다.

## 핵심 주장

### 1. 어휘가 여는 신학
| 단어 | 원어 | 의미 |
|---|---|---|
| 잃은 (양) | ἀπόλλυμι | 깨지다·상하다 (단순 분실 아님) |
| 두고 (99를) | καταλείπω | **버리다** (방치·포기) |

- "잃은 양"은 길을 잃은 양이 아니라 **깨어지고 상한 심령**의 양.
- "두고"는 안전하게 맡겨 두는 것이 아니라 **버리는** 것 — 수지 타산 완전 파괴.

### 2. 1과 99의 대비

| | 1 (잃은 양) | 99 |
|---|---|---|
| 상태 | 상하고 통회 | 자기 의 충만 |
| 자기 인식 | 의가 없음, 길도 진리도 생명도 없음 | 회개할 것 없는 의인 |
| 성경 연결 | 시 51:17; 마 5:3-6 (팔복) | 바리새인 (눅 18:9-14) |
| 완성 | 1이 더해져야 100(완성)이 됨 | 99에서 멈춤 — 미완 |

- 99는 자기 의로 굳어졌기에 카탈레이포(버려짐)를 당함.
- 1이 되어야 목자가 찾아오심.

### 3. 목자의 명예가 걸린 탐색
- 잃은 양(상하고 통회하는 심령)을 찾지 못하면 → **목자의 정체성·명예 전체가 붕괴**.
- "찾을 때까지 찾았다" = **절대 포기 없음**. 하나님의 사랑·정의·명예가 이 한 마리에 걸림.
- 어깨에 메고 귀환: ① 양의 힘없음(스스로 올 수 없음) ② 공동체 앞 명예 회복 선언.
- 잔치: 명예 회복 + **천국 잔치의 예표**.

### 4. 누가복음 15-16장 내부 구조
```
세리·죄인 (1의 무리) ←→ 바리새인·서기관 수군거림 (99의 반응)
   │
   ├─ 잃은 양 (15:1-7)   : 1 vs 99
   ├─ 잃은 드라크마 (15:8-10)
   └─ 탕자 비유 (15:11-32)
        ├─ 탕자 = 1 (상하고 통회하며 귀환)
        └─ 큰아들 = 99 (잔치 불참, 기쁨 없음)
             └─ 16장 부자와 나사로 (나는 의가 많다 = 99의 극단)
```

### 5. 적용: 아픔이 은혜인 이유
- 모든 것이 충족 → 자기 의 견고화 → 99 상태 강화.
- 결핍·아픔·실패·상처 → 자기 의를 깨뜨림 → 1(통회)로 만드는 **하나님의 은혜**.
- 병원: 아파서 온 사람들이 깨어진 상태 → 1이 되는 문 앞에 섬.

> "아픈 게 은혜죠. 잘 안 되는 게 은혜인 거예요."
