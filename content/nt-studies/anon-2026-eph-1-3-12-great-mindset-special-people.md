## 요약

에베소서 1:3-12에 담긴 하나님의 사고방식 세 가지: ①나는 누구인가(과거·현재 규정)가 아니라 나는 누구이고 싶은가(미래·비전이 끌어당김), ②뜻이 있어야 길이 열린다가 아니라 길이 먼저이고 길을 가야 뜻이 나온다, ③인생은 노력과 의지의 산물이 아니라 하나님의 기쁨 안에 있는 것이다. 예정(προορίζω)은 개인을 천국·지옥으로 미리 정한 것이 아니라 "예수 그리스도 안"이라는 울타리가 미리 쳐진 것이다.

## 핵심 주장

### 1. 나는 누구이고 싶은가 — 정체성의 출처 전환

**두 가지 정체성 물음의 차이**:

| | 나는 누구인가 | 나는 누구이고 싶은가 |
|---|---|---|
| 시간축 | 과거·현재 | 미래·비전 |
| 작동 방식 | 본질을 고정 → 변화 불가 | 이상적 자기가 드라이브를 만듦 |
| 인간 유형 | 과거와 현재에 사로잡힌 사람 | 미래가 끌어당기는 사람 |

**테세우스의 배 역설** (플루타르코스):
- 수백 년에 걸쳐 부품을 교체 → 원래 부품이 하나도 남지 않은 배가 "테세우스의 배"인가?
- 적용: 인간에게 변하지 않는 고유한 본질이란 없다

**세포 교체 주기**:
- 몸의 60-100조 세포는 매일 교체: 적혈구(120일), T세포(30일), NK세포(7일), 뼈(7년)
- 7년이면 모든 세포가 교체됨 → 기억조차 본질이 될 수 없음

**성경의 해답 — 하나님이 부르신 이름**:
```
야곱(형 뒤꿈치 잡던 자) → 이스라엘(하나님과 겨루어 이긴 자 / 12지파의 아버지)
아브람(한 가정의 아버지) → 아브라함(열방의 아버지)
= 하나님이 "너는 누구여야 하는가"로 이름을 불러 주심 = 그것이 진짜 정체성
```

**예정(προορίζω) 재해석**:
```
기존 오해: 태초에 천국 갈 자·지옥 갈 자를 개별로 예정
실제 의미: 프로호리조 = 경계를 미리 쳐놓음 = 울타리를 미리 둘러놓음

예정된 것 = "예수 그리스도 안"이라는 울타리 (개인이 아님)
→ 그 울타리 안에 들어가는 자가 구원받는 자
→ 나의 정체성 = "나는 예수 그리스도 안에 있는가?"
```

### 2. 길이 먼저, 뜻은 나중 — 운영체계 전환

**속담 비판**: "뜻이 있으면 길이 있다" → 역방향으로 이해된 것

**닭(운영체계) vs 계란(출력) 비유**:
```
뜻 = 계란 (일회성 출력)
길 = 닭 (운영체계 / 무한 생산)

닭이 먼저 있어야 계란이 계속 나온다
→ 길이 먼저 있어야 뜻이 끊임없이 나온다
```

**역사적 증거 — 경부고속도로** (1968-1970):
```
"차도 없는 나라에 고속도로가 왜 필요한가?" (계란이 먼저라는 사고방식)
→ 길(고속도로) 먼저 건설: 1968년 착공 → 1970년 7월 7일 완공 (428km / 429억원)
→ 이동 시간: 15시간 → 5시간
→ 결과: 고속도로(길)가 생기자 자동차 산업(뜻)이 발전
```

**생물학적 증거 — 태아 발육**:
```
핏줄(길)이 먼저 생기고 → 피(생명·뜻)가 흐른다
```

**성경의 세 증거**:
- **요한복음 14:6**: 예수님은 "길이요 진리요 생명" — "뜻"이 아닌 "길"로 자신을 소개
- **욥기 23:10**: "내가 가는 길을 나도 모르겠으나 그가 나를 단련하시면 내가 정금같이 나오리라" — 방향(뜻)은 몰라도 동행자(길)가 있으면 뜻이 이루어짐
- **시편 23편**: "저가 나를 푸른 초장으로 쉴만한 물가로 인도하시는도다" — 목자가 길을 이끌고 뜻이 따라옴

**핵심**: 뜻은 하나님이 갖고 계심. 예수 그리스도라는 길을 가면 그 위대한 뜻이 내게 이루어짐.

### 3. 기쁨과 설렘 — 인생의 동력 전환

**두 종류의 인생**:

| | 노력과 의지의 인생 | 기쁨과 설렘의 인생 |
|---|---|---|
| 동력 | 죽지 못해 살기에 열심히 함 | 하나님의 기쁘신 뜻을 앎 |
| 상태 | 괴로움을 끙끙 참으며 견딤 | 내가 하나님의 기쁨 안에 있음을 앎 |
| 결과 | 저주받은 인생 | 복된 인생 |

**에베소서 1:5의 근거**:
> "그 기쁘신 뜻대로 우리를 예정하사 예수 그리스도로 말미암아 자기 아들들이 되게 하셨으니"

- 하나님의 구속의 동력 = 의지·노력·초인적 참을성이 아님
- **εὐδοκία(기쁘신 뜻)** = 하나님의 기쁨이 구속의 출발점

**구속사의 전체 구조**:
```
시작: 에덴 동산 = 기쁨의 장소
끝: 거룩한 성 예루살렘 (계 22장) = 기쁨의 완성
→ 하나님의 창조·구속·완성은 기쁨의 여정
```

**인생이 기쁨이 되는 조건**:
```
회장님이 기대를 갖고 볼 때 → 직장이 기쁨
선생님이 기대를 갖고 볼 때 → 학교가 기쁨
부모의 뜻을 알 때 → 자녀의 인생이 기쁨

→ 나를 지으신 하나님 아버지의 기쁘신 뜻을 알면
→ 인생은 기쁨과 설렘이 됨
```
