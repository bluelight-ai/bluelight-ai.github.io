## 요약

마태복음 6:25-34는 산상수훈의 실전편이다. 핵심 구조는 세 그룹 비교: 먹고 입고 마시는 것을 걱정하며 솔로몬의 영광을 꿈꾸는 인간(이방인) < 하나님이 먹이고 입히시는 공중의 새·들의 백합화(보편 은총) < 하나님을 아버지라 부르는 "너희"(특별 은총). 염려하는 자들은 내일을 가진 자들이고, 특별 은총 안에 있는 "너희"는 내일이 없는 자들 — 영생 = 시간이 멈춤이다.

## 핵심 주장

### 1. 세 그룹 비교 구조

```
그룹 1: 인간 (ψυχή / 이방인)
  먹을 거·마실 거·입을 거·누울 거·타고 다닐 거 걱정
  → 복잡한 욕망의 신경망 (무한히 세분화)
  → 그 정점 = 솔로몬의 영광 (지구 역사 상위 0.001%)
  → 현대: SNS·유튜브가 욕망 해킹 → 상위 1%와 비교
  = "이방인들이 구하는 것"

          ↓ 솔로몬의 영광이 이것보다 못함

그룹 2: 공중의 새 / 들의 백합화
  심지도 않고 거두지도 않고 길쌈도 않음
  → 하나님이 먹이고 입히심
  → 솔로몬의 모든 영광이 이 꽃 하나만 못함
  = 하나님의 보편적 은총

          ↓ 너희는 이것보다도 귀함

그룹 3: 너희
  하나님을 아버지라 부르는 자들 (주기도문)
  = 특별한 은총 = 영생 = 내일이 없는 자들
```

**왜 인간 문명(솔로몬) < 보편 은총인가?**
- 인간 문명의 최첨단이 만들 수 없는 것: 세포 하나, 공기, 물, 꽃 한 송이
- 공기·물·햇빛·자연 전체 = 하나님이 부어 주신 보편 은총
- 솔로몬의 영광(인간 문명 최첨단) < 들에 핀 꽃 하나(보편 은총)

---

### 2. 엘리야 예화 (왕상 17장) — 보편 은총이 특별 은총을 섬김

```
착각: 이스라엘이 비(농경의 핵심)를 바알이 준다고 믿음
  → 하나님이 비를 3년 반 끊음 = 보편 은총 끊음 → 기근

까마귀 → 엘리야에게 떡과 고기를 먹임:
  까마귀 = 보편 은총만 의지 = 특별 은총을 섬김
  = "공중의 새를 보라" 구조의 구약 실현

사르밧 과부 (이방 여인):
  보편 은총이 끊어짐 → 마지막 기름 한 방울을 특별 은총(엘리야)에게 줌
  → 특별 은총이 그에게 흘러옴 → 기름이 끊이지 않음

구조:
  보편 은총이 특별 은총을 섬김
  → 보편 은총 받은 자들이 특별 은총 안으로 들어옴
```

---

### 3. 영생 = 시간이 멈춤

**"내일 일은 내일이 염려할 것이요" (마 6:34)**:

| | 보편 은총만 받은 자 | 특별 은총 받은 자 |
|---|---|---|
| 시간 구조 | 어제 → 오늘 → 내일 | 오늘(영원한 현재) |
| 상태 | 시간의 흐름 속에서 사라짐 | 시간이 멈춤 = 영생 |
| 염려 | 내일을 가졌기에 염려함 | 내일이 없으므로 염려 불필요 |
| 정체성 | 이방인 | 하나님의 자녀 |

- 영생은 죽지 않는 것이 아니라 **시간이 멈춤** — 지금 이 순간이 영원
- 하나님의 생명 질서 안으로 들어간 자 = 이미 내일이 없는 자

---

### 4. 하나님 나라와 그의 의를 구하라 (마 6:33)

```
하나님 나라 (βασιλεία):
  하나님의 통치·주권이 내 안에 이루어짐
  = 팔복이 내 안에 현실이 됨

그의 의:
  예수 그리스도의 의
  → 하나님을 만족시킬 의는 내게 없음
  → 예수 그리스도의 의를 내 마음에 가져옴
  → 그 이름으로 하나님을 아버지라 부름 = "너희"

"이 모든 것을 더하시리라":
  특별 은총을 구하면 → 보편 은총(먹고 입고 마시는 것)은 따라옴
```
