## 요약
여리고 맹인 치유는 단순한 기적이 아니라 "누가 하나님 나라에 들어가는가"를 보여주는 장면이다. ἀναβλέπω(다시 봄)는 영적 시각 회복이며, 무너진 여리고처럼 철저히 깨진 자가 가나안(하나님 나라)에 들어간다. 양심·율법의 목적은 의롭게 살라가 아니라 내가 볼 수 없는 자임을 깨닫게 하는 것이며, 마틴 루터가 그 돌파구를 보여준다.

## 핵심 주장

### 1. ἀναβλέπω — "다시 보다"의 신학적 의미

- βλέπω: 단순한 물리적 시각
- **ἀναβλέπω**: 다시 보다 / 위를 보다 — 복음서의 맹인 치유 장면에서 일관되게 사용
- 단순한 시각 기적이 목적이 아님
- **질문**: 누가 하나님 나라를 보게 되는가? 누가 그리스도 메시아를 알아보는가?

### 2. 여리고 지형 신학

```
여리고 → 예루살렘 (출애굽 후 가나안 입성 경로)
여리고 = 무너져야 가나안에 들어갈 수 있는 곳 (수 6장)
```

- 여리고에 앉아 있는 맹인 = **무너진 자**
- **길가에 앉음**: 길(진리) 안이 아니라 진리 바깥 → 자기가 맹인임을 깨달아 철저히 무너진 자
- 무너진 자 = 가나안(하나님 나라)에 들어가는 자

### 3. 부자 관원 vs 여리고 맹인 대비

| | 부자 관원 | 여리고 맹인 |
|---|---|---|
| 자기 인식 | "내가 할 수 있다" | "내가 보지 못한다" |
| 율법 끝자락 도달 | 아직 부족한 것이 있다 여김 | 그 길로는 볼 수 없음을 깨달음 |
| 입에서 나온 말 | "내가 어떻게 하여야 영생을 얻으리이까" | "주여 나를 불쌍히 여기소서" |
| 결과 | 근심하며 돌아감 | 다시 보게 되어 예수를 따름 |

### 4. 양심 = 율법의 목적 재해석

양심대로 100% 산 사람은 없다. 40명 중 아무도, 70억 명 중에도 없다.

**논증**:
- 만약 양심의 목적이 "양심대로 살라"라면 → 그 목적을 이룬 사람이 있어야 함
- 아무도 없음 → 양심의 목적이 "양심대로 살라"가 아님

**양심의 실제 목적**:
> 내가 하나님 앞에 의롭지 못한 죄인임을, 내가 볼 수 없는 자임을 깨닫게 하는 것

```
양심·율법 → 선할 수 없는 자기 폭로 → "나는 보지 못하는 자다" 자각
           → "주여 나를 불쌍히 여기소서" → 하나님의 은혜 → 다시 봄
```

자기 의("내가 할 수 있다")를 근거로 하나님께 나아가는 것 = 얼마나 터무니없는가를 양심이 보여준다.

### 5. 마틴 루터 예화 — 자기 의의 한계와 로마서의 돌파

**10년간의 혹독한 자기 의 추구 (1505~)**:
- 고해 성사 하루 3~4회, 회당 6시간 (행동 + 동기까지 고백)
- 수일간 단식, 장시간 무릎 기도
- 목표: 행위·의지·동기까지 선하게 만들어 하나님 앞에 의롭다 인정받기

**결과**:
- 마음속: **"지옥 같다"**
- 하나님 = 두려움의 대상, 미움의 대상
- 선할 수 없는 자기 자신 발견

**돌파 — 로마서 1:17**:
> "오직 의인은 믿음으로 말미암아 살리라"

- 의롭다 인정받는 것 = 내 행위로 쟁취하는 것이 아니라 **하나님이 거져 주시는 은혜의 선물**
- 결과: **천국의 문이 열림**

루터의 여정 = 자기 의(부자 관원) → 내가 볼 수 없는 자임의 자각(맹인) → 은혜(다시 봄)

### 6. 다시 봄 = 은혜를 받는 구조

```
"내가 볼 수 있다" → 내 행위로 의를 쟁취 → 문 닫힘
"내가 볼 수 없다" → "주여 나를 불쌍히 여기소서" → 하나님의 은혜 → 다시 봄
```

육안의 눈이 닫히고 → 영적인 눈, 하나님 나라를 보는 눈, 그리스도를 보는 눈이 열림

## 주요 용어
- **ἀναβλέπω (아나블래포)**: 다시 보다/위를 보다 — 단순 시각 회복이 아닌 하나님 나라를 보게 됨
- **여리고**: 무너져야 가나안에 들어가는 곳 → 철저히 깨진 자가 하나님 나라에 들어감
- **길가**: 진리(길) 바깥 → 자기가 맹인임을 깨달은 자의 자리
- **양심**: 내가 볼 수 없는 자임을 깨닫게 하는 도구 (의롭게 살라는 명령이 아님)
- **"주여 나를 불쌍히 여기소서"**: 자기 의 포기, 내가 볼 수 없는 자임의 고백 → 다시 보게 됨의 문
- **마틴 루터**: 10년 자기 의 추구 → 지옥 같은 마음 → 로마서 1:17 → 은혜로 의롭다 함(이신칭의)
